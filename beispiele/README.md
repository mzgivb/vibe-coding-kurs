# Beispielprojekte

Zwei fertige, **per Vibe Coding gebaute** Projekte zum Anschauen und Ausprobieren. Sie begleiten
die Praxis-Module. 🏠 [Zurück zur Übersicht](../README.md)

| Projekt | Typ | Passt zu | Starten |
|---|---|---|---|
| [`webseite/`](webseite/) | HTML/CSS/JS | [Modul 3](../module/03-erste-webseite.md) | `index.html` im Browser öffnen |
| [`notizen-app/`](notizen-app/) | Electron-Desktop-App | [Modul 5](../module/05-electron-app.md) | `npm install && npm start` |

Du musst diese Projekte nicht selbst bauen – sie zeigen, was mit Vibe Coding möglich ist, und
dienen in den Modulen als Vorlage zum Erweitern.
