# Beispiel: Interaktive Webseite

Eine per Vibe Coding gebaute Webseite zum Thema Vibe Coding – mit Startansicht, Infokarten und
einem kleinen Quiz. Sie gehört zu [Modul 3](../../module/03-erste-webseite.md).

## Starten

Doppelklick auf `index.html` – die Seite öffnet sich im Browser. Mehr ist nicht nötig.

## Dateien

| Datei | Aufgabe |
|---|---|
| `index.html` | Struktur und Inhalt der Seite |
| `style.css` | Aussehen (Farben, Layout, Animationen) |
| `script.js` | Verhalten (Navigation, Quiz-Logik) |

## Selbst weitermachen

Öffne den Ordner in deinem Werkzeug (Chat-KI oder opencode) und beschreibe Änderungen, z. B.:

> Füge der Seite einen Dunkelmodus-Schalter hinzu.

> Ergänze das Quiz um zwei weitere Fragen.

Nach jeder Änderung den Browser neu laden und testen.
